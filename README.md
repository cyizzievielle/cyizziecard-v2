## ✦ Overview

**cyizziecard v2** is a crafted personal bio-link hub designed with modern web aesthetics, dynamic micro-interactions, responsive sound chimes, and an interactive **Cigarettes After Sex** ambient music showcase. 

Built with **pure Vanilla HTML, CSS, and JavaScript** — zero frameworks, ultra-fast load times, and buttery-smooth animations.

---

## 🎨 5 Aesthetic Themes

Switch themes seamlessly on the fly with the floating Gen-Z glassmorphic picker:

| Theme | Aesthetic Mood | Highlights |
| :--- | :--- | :--- |
| **🍓 Matcha Signature** *(Default)* | Velvety dark tea & soft berry | Drifting strawberry petals, soft glowing badges, matcha neon accents |
| **📼 CAS Midnight Monochrome** | Pure 100% film noir black & white | Deep black backgrounds, silver scanlines, grayscale photography & vinyl |

| **🧸 Kidcore Sticker** | Playful pastel neo-brutalism | Chunky 2.5px dark borders, bold sticker drop-shadows, candy pill buttons |

## ✨ Interactive Features

- 💿 **Real Vinyl Disc Player** — Spinning album art synchronization with interactive audio visualizer equalizer bars.
- 🎵 **Instant Track Gallery** — 8 Cigarettes After Sex tracks with real album artwork, instant live switching, and embedded Spotify integration.
- 🎴 **CAS Lyric Deck** — Draw randomized melancholic song lyrics and album quotes with smooth flip transitions.
- 🥤 **Interactive Sip Lab** — Real-time atmosphere color-shifting sliders adjusting strawberry & matcha saturation on the fly.
- 🫙 **Jar of Midnight Thoughts** — Tap to uncork randomized late-night reflections with pop feedback.
- 🌌 **Adaptive Ambient Canvas** — Dynamic falling particles that automatically adapt their physics, shapes, and colors depending on the active theme (petals, stardust, rain streaks, pixel blocks, confetti).
- 🔊 **Sound System** — Web Audio API synthesized soft chimes on interactions with mute toggles.
- 📋 **One-Click Quick Copy** — Copy email, username, and share links with animated floating toast notifications.

## 🛠️ Tech Stack

- **Styling**: Vanilla CSS3 (Custom CSS Properties, Glassmorphism, CSS Grid, Flexbox, Keyframe Animations)

## 🚀 Getting Started

Clone the repository and run locally in seconds:

```bash
# Clone the repository
git clone https://github.com/cyizzievielle/cyizziecard-v2.git

# Enter the directory
cd cyizziecard-v2

# Open directly in your browser or run with a local server
# (Using Python)
python -m http.server 3000

# (Or using npx serve)
npx serve .
```
